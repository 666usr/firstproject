# csv-insight

Маленькая программа на Python, которая читает CSV-файл и печатает по нему короткий отчёт: сколько строк и колонок, какие данные в каждой колонке, где пропуски, минимум/максимум/среднее для чисел и самые частые значения для текста.

Это мой первый учебный проект. Цель - пройти полный цикл: написать код, запустить его, залить на GitHub и объяснить, что он делает.

## Что умеет

- читает CSV-файл (по умолчанию `data/sample.csv`);
- для каждой колонки определяет тип: числовая или текстовая;
- показывает количество пропусков (пустых значений);
- для числовых колонок: минимум, максимум, среднее;
- для текстовых колонок: число уникальных значений и топ-3 самых частых;
- может показать только одну колонку (`--column`);
- умеет сохранять отчёт в текстовый файл (`--out`);
- покрыт простыми тестами;
- вежливо сообщает об ошибке, если файла нет или он пустой.

## Как запустить

Нужен только Python 3. Сторонние библиотеки не требуются.

```bash
python main.py
```

Отчёт по файлу с примером данных. Другие возможности:

```bash
python main.py path/to/your_file.csv      # свой файл
python main.py --column city              # только одна колонка
python main.py -o report.txt              # сохранить отчёт в файл
python -m unittest -v                     # запустить тесты
```

Пример вывода:

```
Отчёт по файлу: data/sample.csv
Строк: 10   Колонок: 5
----------------------------------------------

- age  [числовая]
    пропусков: 1
    минимум: 25
    максимум: 45
    среднее: 33.56
```

## Как работает (по шагам)

1. `read_rows` открывает файл и читает его через стандартный модуль `csv`.
2. `summarize` считает статистику по одной колонке.
3. `as_number` решает, является ли значение числом.
4. `print_report` печатает аккуратный отчёт в консоль.
5. `main` принимает путь к файлу из командной строки и обрабатывает ошибки.
